# ビジュアル強化の発注リスト(Codex向け)

対象: hirameki-koubou_v2。機能・出題契約は正しく動いている前提で、見た目が弱い箇所だけを強化する。

## 全体の制約(全項目に共通)

- `docs/visual_design_v1.md` の基準に合わせる: 濃紺の工房フレーム、生成りの紙、塗装した木製玩具の質感
- 正確さが必要な教材図(数直線・時計・グラフ・ブロック・マス)は HTML/CSS/SVG のまま。画像に置き換えない
- 盤面は「問題の状態」だけを見せる。答え・正誤・過不足を絵で漏らさない
- 問題文の呼び名と絵は必ず一致させる(りんごと呼ぶならりんごを描く。逆に まる と呼ぶ問題は丸のまま)
- 変更後は `node --test tests/quality-contract.test.mjs` と、サーバを立てて `node tests/browser-sweep.mjs` が緑であること(スイープは390px幅で全問の横はみ出しを検査する)
- 絵文字は使わない

## 優先度A(学習の理解に直接効く)

1. **なかまわけ・かたちのなかまの対象カード**(`object-card` 盤面)
   - 現状: 「つみき」「ティッシュの ケース」等が文字だけのカード
   - 発注: 各対象の小さな絵(SVGまたはアトラス画像)。対象は solve.js の CARD_SETS と shape.js の OBJECTS の全語
   - 完了条件: 文字を読めない子でも対象が分かる。語と絵の対応はデータ上ペアで持つ

2. **かさくらべの入れ物**(`cups` 盤面)
   - 現状: カップの列だけで、くらべている「すいとう・ペットボトル・やかん」の絵がない
   - 発注: あ/い のラベル横に入れ物本体の小さな絵。カップ列(数の根拠)はそのまま残す
   - 完了条件: 問題文の入れ物名と絵が一致。カップの数は今まで通り数えられる

3. **かくれたぶんの箱**(`hidden-split` 盤面)
   - 現状: 破線の枠に「？」だけ
   - 発注: ふた付きの木箱らしい絵(閉じたふたが見える)。？は残す
   - 完了条件: 「かくれている」ことが絵で伝わる

## 優先度B(世界観の没入に効く)

4. **導入2ページ目の絵**
   - 現状: ルミナが止まった場面が「・・・」の暗いプレースホルダ
   - 発注: 工房が暗くなりルミナが止まった場面の1枚絵(既存の workshop-hero-v1.jpg とトーンを合わせる)
   - 完了条件: 3画面の導入が絵つきで通して見られる

5. **ホームの6ライン カード**
   - 現状: 色帯+文字のみ
   - 発注: 各そうち(かずの けいじばん・あわせる そうち・わける そうち・はかる だい・かたちの つくえ・しらべる つくえ)の小さな装置アイコン
   - 完了条件: 文字を読まなくても どのそうちか区別できる

6. **結果画面の修理演出**
   - 現状: 文字(「そうちが うごきだした」)と星だけ
   - 発注: クリア時に装置が動き出す・工房が少し明るくなる小さな演出(静止画の差し替えか軽いCSSアニメ)
   - 完了条件: 正解の積み重ねで世界が変わった感が出る。演出は3秒以内でスキップ可能

7. **わけっこの人物**(`share-people` 盤面)
   - 現状: 紺色の無地シルエット
   - 発注: トト・モクモ風の小さなキャラ絵(2〜5人分)
   - 完了条件: 人数が数えやすいまま、キャラとして見える

## 優先度C(質感の底上げ)

8. **立体の絵**(`solid` 盤面: はこ・さいころ・つつ・ボール)
   - 現状: 単色の簡易SVG
   - 発注: 木製玩具の質感(面の塗り分け・ハイライト)。ましかく/ながしかくの面の違いが今より分かりやすく
   - 完了条件: 面の形の学習(スタンプ問題)を妨げない

9. **くだもの・こまのSVG磨き**(りんご・みかん・ぶどう・いちご・どんぐり・ボタン・つみき・おはじき)
   - 現状: 機能的には十分な自作SVG
   - 発注: 玩具らしい質感に統一(枠線・影・ハイライトのトーン合わせ)
   - 完了条件: 15px程度まで縮んでも判別できる(ならべ比べで最小サイズになる)

10. **ものさしブロックの帯**(`block-ruler` 盤面)
    - 現状: ぼう/リボン/テープの色分けはあるが簡素
    - 発注: 8の おなじ質感に合わせる。テープの端・リボンの切り込みなど形の特徴を保つ
    - 完了条件: 帯の右はしの位置(答えの根拠)がぼやけない

## 発注しないもの(現状維持)

- 時計・数直線・マス目・えグラフ・10のわく: 正確さ優先でHTML/CSS描画のまま
- ヒント・説明パネル、けってい等の操作UI: 現行の共通文法を崩さない
